# Melhorar UI

A tela esta muito fora dos meus padrões, vamos usar bootstrap para melhorar a nossa UI.

Prefiro um menu lateral para navegação, e o conteudo com width menor e centralizado.
Pode usar icones e usar cores normais, se disponivel fazer usando darkmode.

## Execução

Vou trocar o Pico.css v2 pelo Bootstrap 5.3 (CDN), mantendo o dark mode nativo via `data-bs-theme="dark"`. A navegação vira um menu lateral com o padrão `offcanvas-lg` do Bootstrap: sidebar fixa no desktop e gaveta com hambúrguer no mobile, com ícones via Bootstrap Icons. O conteúdo fica centralizado em uma coluna estreita (~760px) ao lado da sidebar. A paleta passa a ser a padrão do Bootstrap (azul primário + cores contextuais por semântica: contact→primary, finance→success, schedule→warning, notes→info, add→success, require→warning, reminder→warning, todo→info), saindo o gradiente indigo/violeta. As classes semânticas atuais (`badge-cat-*`, `badge-kind-*`, `badge-note-*`, `segment-*`, `todo-*`, `note-*`, `badge-match-*`) serão mantidas e apenas reestilizadas no `app.css`, então os testes de views não mudam. Nenhuma lógica Go é alterada; só templates, CSS e os CDNs do `base.html`.
