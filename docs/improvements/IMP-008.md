# Melhoria do CLI

Hoje o CLI (Command Line Interface) do bot é muito limitado e não possui muitas funcionalidades. Isso dificulta a utilização do bot, pois o usuário precisa digitar comandos complexos para realizar ações simples.

Uma forma de melhorar isso é criar um CLI mais amigável e intuitivo, com comandos mais simples e fáceis de lembrar. Além disso, podemos adicionar funcionalidades que facilitem a utilização do bot, como a possibilidade de listar os comandos disponíveis, exibir mensagens de ajuda e fornecer feedback ao usuário sobre as ações realizadas.

Pensei em usar uma biblioteca, https://go-tui.dev/. Elá é bem conhecida é ja em Go, então não precisamos nos preocupar com dependências externas. Ela também é bem documentada e possui exemplos de uso, o que facilita a implementação.
