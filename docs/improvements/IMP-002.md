\# UI improvemente



Até agora tenho usado o front básico para manter tudo o mais simples possível. Antes de avançarmos para os próximos passos, quero manter o ui sendo servido pelo server, mas quero dar uma melhorada. Digo melhorar visualmente, com um aspecto mais moderno, sem usar react nem essas coisas, quero manter simples, mas bonito.



Para isso pode alterar o css que estou usando atualmente, me dê opções nomeadas antes de escolher, assim posso ver online exemplos, sendo o caso de ser algum framework pronto.



Além de mudar o estilo, pode sugerir mudanças na estrutura atual se for necessário.

## Execução

Vou manter o Pico.css v2 como base e adicionar uma camada de CSS própria por cima, com a paleta indigo→violeta e a fonte Inter. A mudança é só de apresentação: um arquivo CSS novo servido estaticamente, ajustes nos templates (navbar com marca, badges coloridos, cards de resultado estruturados, indicadores de loading) e um helper de tradução para os rótulos dos badges. Nenhuma lógica de negócio muda.

## Implementação (UI Refresh)

Implementado em 2026-09-23: camada de CSS própria (`web/static/css/app.css`) carregada após o Pico v2, servida via `router.Static("/static", "./web/static")`. Paleta indigo→violeta via custom properties do Pico, tipografia Inter (Google Fonts CDN), navbar fixa com blur e marca em gradiente, badges coloridos por categoria/ação (texto PT-BR via helper `label` registrado no `views.FuncMap`), card de resultado estruturado com trilha de segmentos, spinners de loading nos botões (htmx `hx-indicator`/`hx-disabled-elt`), tabelas com scroll horizontal e zebra, card de erro avermelhado e transições suaves de swap. Nenhuma mudança de arquitetura Go além do static file serving; fluxos de dados inalterados.
