# Validation before adding new data to the database

Os tipos de dados que temos funcionando por agora são:
- Contato
- Notas
- Finanças

Pode ser que em algum momento o usuário tente adicionar algum dado que já está salvo, principalmente no caso de contatos e finanças. Para evitar duplicidade de dados, podemos implementar uma validação antes de adicionar novos dados ao banco de dados.

Acredito que para nome é mais fácil ja que temos menos campos para validar, mas para finanças pode ser mais complicado, pois o usuário pode adicionar uma transação que já existe, mas com um valor diferente ou em uma data diferente. Então precisamos pensar em como podemos validar esses dados antes de adicioná-los ao banco de dados.

Por isso essa tarefa é para pensar em como podemos validar os dados antes de adicioná-los ao banco de dados, para evitar duplicidade de dados e garantir que o usuário não adicione dados que já existem.

O próximo tópico será preenchido com as ideias que eu tive para validar os dados antes de adicioná-los ao banco de dados. Se você tiver alguma ideia, por favor, adicione nesse tópico.
