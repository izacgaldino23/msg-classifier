# Redirecionar após classificação

Por agora o que quero fazer é começar montar o fluxo ponta a ponta para a categoria de contato. 

Como primeiro passo, após a solução jev retornar que é essa categoria que o usuário deseja, "contact", preciso redirecionar para o serviço/caso de uso específico, que vai redirecionar corretamente para o caso de adição ou requisição (get). 

Ainda não planejei bem como vou extrair os dados da mensagem. Mas por enquanto, vamos elaborar a estrutura simples, para que quando eu for implementar os outros seja fácil de adicionar, seja por switch ou por hashmap, como são poucas categorias podemos usar o mais fácil de implementar.

Eu acredito que talvez seja melhor ter dois caminhos separados uma para cada (adicionar e buscar). Mas por agora vamos focar somente no de adicionar como first step.

## Implementação (2026-09-22)

Estrutura de dispatch implementada conforme o design:

- **`models.KindFinding.Value`** — valor resolvido do kind (`"add"` / `"require"` / `"both"`), derivado do score via `round(score)` → índice → `legend[index]` em `ClassificationService.Classify` (uma única chamada Jev com `classification.json`, que contém as duas perguntas).
- **`models.UseCaseOutcome`** — `{Classification, Action}` com constantes `ActionNone` e `ActionContactAdd`.
- **`services.Dispatcher`** — registro `map[string]CategoryHandler` chaveado por `Category.Choice`; miss → `ActionNone`. Interface `CategoryHandler.Handle(request, classification)`.
- **`services.ContactService`** — handler da categoria `contact`: kind `add`/`both` → stub `Add` → `ActionContactAdd` (extração/persistência TODO); kind `require` → `ActionNone` (caminho get TODO).
- **`MessageController.ReceiveMessage`** — bind → `Classify` → `Dispatch` → `RenderResult(outcome.Classification)`; TODO de banco movido do controller para o `ContactService`.
- **`cmd/api/main.go`** — `ContactService` registrado no `Dispatcher` (uma linha).
- Falhas de resolução de kind (índice fora do range, chave ausente, legend vazio) → `ErrUpstream` → HTTP 502.
